# 🎓 Marketing Integral LMS

**Interactive Learning Management System · UNIR Alta Gerencia**

LMS interactivo de página única para la asignatura Marketing Integral, construido con HTML + CSS + Vanilla JS + Anthropic API.

---

## ✨ Características

| Feature | Descripción |
|---------|-------------|
| 📚 9 Temas | Temario completo con lecciones estructuradas |
| 📄 Lecciones IA | Generación automática con contexto UNIR vía Anthropic API |
| 🃏 45 Flashcards | 5 por tema, con animación 3D flip y filtros por tema |
| 📝 9 Tests | 5 preguntas por tema con feedback inmediato |
| 📖 Glosario | 38 términos con búsqueda en tiempo real y filtros por tema |
| 🎓 Tutor IA | Chat multi-turn con contexto completo UNIR |
| 🔗 Recursos | Fuentes externas por tema (AMA, HBR, HubSpot, etc.) |
| 💾 Progreso | Persiste entre sesiones vía localStorage |
| 🔑 API Key UI | Modal integrado para configurar la Anthropic API key |

## 🚀 Uso rápido

Abrir `index.html` directamente en el navegador.

Para activar las funciones de IA, pulsar el botón **🔑 API Key** en la barra superior y pegar tu Anthropic API key.

## 🗺️ Vistas disponibles

- **Panel principal** — Estadísticas de progreso y acceso a temas
- **Tema** — Lista de lecciones + test de evaluación por tema
- **Lección** — Contenido generado por IA con contexto UNIR
- **Test** — 5 preguntas con feedback inmediato y explicación
- **🃏 Flashcards** — 45 tarjetas con flip 3D, filtradas por tema
- **📖 Glosario** — 38 términos con búsqueda y filtros
- **🤖 Tutor IA** — Chat académico con Prof. Marketing IA
